# Advanced Supply Chain & Inventory Analytics

An advanced data analytics project using Excel, MySQL and Power BI to analyze sales, profitability, inventory, suppliers, warehouses and delivery performance.

## 📊 Project Overview

This project analyzes a multi-table supply chain dataset to identify business trends and operational performance across:

- Sales and profitability
- Product categories
- Warehouses
- Suppliers
- Customer segments
- Inventory levels
- Delivery performance
- Returns

## 🛠️ Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI
- DAX
- Power Query

## 📁 Dataset

The project contains multiple connected tables:

- Orders — 3,500 orders
- Products — 120 products
- Suppliers — 25 suppliers
- Warehouses — 8 warehouses
- Customers — 900 customers
- Inventory — 1,800 inventory records

## 📈 Key KPIs

- Total Orders

- Total Profit
- Profit Margin

- Stockout Records

## 📊 Power BI Dashboard

The interactive dashboard includes:

- Monthly Sales Trend
- Sales by Category
- Profit by Warehouse
- Average Delivery Days by Warehouse
- Return Rate by Category
- Inventory Stock Status
- Warehouse, Region and Category filters

## 🔍 Key Analysis Areas

### Sales & Profitability
Analyzed sales, profit and profit margin across products, categories and warehouses.

### Inventory Analytics
Analyzed stock levels, stock status, days of cover and stockout records to identify inventory risks.

### Supplier Analytics
Compared supplier ratings and lead times to understand supplier performance.

### Delivery Analytics
Analyzed delivery days and on-time delivery performance across warehouses.

### Customer Analytics
Analyzed customer segments and regional performance.
